# 失败案例：同维度向量被误认为可以混用

## 现象

知识库原先用模型 A 生成 512 维向量，查询改用模型 B，也返回 512 维。数据库可以正常计算余弦相似度，但检索结果近似随机。

## 根因

维度相同只说明向量长度一致，不说明坐标轴具有相同语义。不同模型版本、不同归一化策略和不同任务训练得到的是不同向量空间。

## 当前处理

索引同时记录 `embedding_model` 和 `embedding_dimensions`。检索要求两者都与当前客户端一致；索引更新发现任一变化时，强制重新向量化整个项目，而不是只处理内容变化的文件。

## 面试结论

Embedding 模型是索引 Schema 的一部分。升级模型属于数据迁移，不是普通配置热更新。
